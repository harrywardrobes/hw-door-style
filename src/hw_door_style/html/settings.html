Ideas to connect the two
  • Material types - board colours as Sheet good (18 / 22 / 25 mm, your HPP sheet sizes), woodgrains marked grained; hinges, TIP-ON and Interfit boxes as Hardware so they are counted, not cut.
  • Bought-in doors & drawer fronts - tag them (e.g. bought-in) so OpenCutList can leave them off the cutting diagrams; the plugin's Door order stays the supplier list.
  • Part tags - DOOR, DRAWER_FRONT, SHELF, DIV, FACING ... on each component so the cut list can be filtered and labelled.
  • Grain direction - lock it on doors and drawer fronts (vertical / horizontal) when you start using woodgrains.
  • Colours first - parts with "Default (no material)" are grouped as no material, so apply colours before running the cut list (the plugin could warn).
  • Runouts - the cut list uses the drawn sizes, so press the pencil (scribes on) before cutting.
