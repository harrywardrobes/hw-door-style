Components

One row per library component: what it is, its Pod letter, its depth. Everything the plugin decides about a component starts here.
Component table
ComponentWhat it isProduct nameLetterDepthOptions
A name also covers copies (WARDROBE#2) and longer names (WARDROBE_LEFT, DRAWER_FITTED_V3); the longest match wins. A component not listed is ignored.
Unit: a product of its own, numbered with its letter (Wardrobe 824 = T1). Part of a product: belongs to the unit it sits in, under or on (a box end under a worktop, the bridge frame on its skeleton); on its own it's a product, and the same ones next to each other make one (box shelves). Internal: only ever inside a unit with the same letter (int drawers in a T). Never a product: bullnose, end panels, cable outlets. Door / Drawer front / Internal drawer front / Fixed panel: the parts the Door style window redraws (a fixed panel is on the door order like a door, but flat, no hinges or handles). Room: floor and ceiling - kept in the job template, never exported.
Depth (back wall to the back of the facing): Standard, Bridge / worktop, or the component's own mm. Options: a door that never gets a mid-rail; a unit whose drawer fronts get the door frame all round.

The letters in list order with what they mean on the PDFs, e.g. T: Tall units, W: Wall / bridge units, B: Base units, F: Facings. Each letter is numbered on its own (T1, T2... W1...); a component with no letter takes the first.
